# DATA-ROUTE-01：继续FC2还是切换FT3D

目的：比较从同一FC2保存点出发，在相同低学习率、输入尺寸、训练步数和增强条件下，更换数据是否改善Sintel。S/L分别比较；不是重复标签截断实验，也不是直接复现旧FT3D配方。

## 固定设置

- 父模型：各自第100轮、69500步的冻结`last`，位于`20260919-fc2-label01-diagnostics/{s,l}_clip50/snapshot`。不使用150轮末尾覆盖父模型。初始化核对模型和BN张量，两个分支都新建Adam，阶段步数归零。
- 四个单卡分支：S-FC2、S-FT3D、L-FC2、L-FT3D。架构、batch/microbatch=32、352×480随机裁剪、种子42、损失、梯度阈值200不变，不加图像或几何增强。
- 每支20000次更新，LR从1e-5余弦降至1e-6。每500步作为一个记录区间，CSV的40个epoch是这些区间，**不是遍历数据集40遍**。每个区间重新洗牌、取前500批，两种数据使用同样规则。
- 两个加载器都以像素为训练/预测单位，训练标签逐分量±50；FT3D设divisor=1。旧FT3D配方的divisor=12.5及强增强不用于这个对照。验证标签保留原值，预测尺度=1；不能拿FT3D内部验证与FC2内部验证直接排名。
- FT3D使用clean+final、左相机、前后向，沿用14条历史排除路径；本次路径验收后有效训练80578、验证15730配对。图像尺寸与有限值只抽样解码，训练采用严格读取，遇到损坏数据报错，不静默换样本。
- FP32、TF32关闭、同一Sofia容器。一卡配24 CPU；FC2加载8线程、FT3D加载16线程、验证8线程，训练预取1批、验证不预取；线程数不改变配方。数据测试对4/8/16线程的相同批次指纹一致，短测试存在缓存/顺序影响，实际收益看训练的data_seconds/update_seconds。

## 验收和选优

`tools/hpc/run_data_route.py --variant s_ft3d --mode probe`等四组先各执行50步、退出、再恢复至100步。核对父权重、同模型初始指纹、S/L的250/390个训练状态张量恢复、NumPy/Python随机数状态保存，以及Sintel输出单位。probe独立目录，不作为正式起点。

通过后以`--mode train --prefetch 1`启动四个独立正式作业，建议每作业12小时；调度账户和资源提交前查询。每1000步做76对快检，每5000步做845对完整监控，196对留出不用。内部数据验证只取顺序前20批作诊断，最终选优看共同Sintel监控；FC2的20批恰好覆盖640对。

比较相同5000/10000/15000/20000步结果和可恢复最佳权重。若FT3D更好，只能归因于本次固定配方下更换数据的效果；若FC2更好，也不能推断历史FT3D完整配方无效。后续可再测试强增强或历史缩放配方，但应独立命名。选中的完整训练方案最终换独立种子重跑。

## 文件与接续

代码入口生成完整JSON配置，保存于`/runs/DATA-ROUTE-01/control/<mode>-<variant>-pf1/`，与job manifest一起记录Git提交和父权重SHA256。训练输出位于`/runs/DATA-ROUTE-01/<mode>-<variant>-pf1/model_*`。运行索引登记父模型，wiki仅在现有实验总表新增一条研究记录。

训练器支持`updates_per_epoch`，不设置时保持原完整epoch行为。新状态文件记录Python或NumPy RNG类型，兼容原FC2旧格式；预取在验证和保存前暂停，并回到最后实际消费的批次位置，记录区间边界可恢复随机状态。固定检查点保留修复仍有效。运行失败先检查日志，不覆盖或无条件重启同一输出目录。


## 训练量与预取结论

FT3D每支20000步、每批32对，共抽取640000对，相当于80578对训练数据的约7.94遍。每500步重新洗牌，因此这是训练量的折算，不表示每个样本恰好遍历8遍。先完成这段共同预算的比较，再根据Sintel曲线决定哪条路线值得延长；不是完整训练的最终轮数。

预取1批的短训练循环约快1.7–1.9倍，深度2没有稳定额外收益；总作业还包括验证与保存，不能按该倍率直接保证完工时间。真实输入、随机状态和中断恢复已检查。L/FT3D的数值异常经确定性计算复核，FC2测速收尾错误已修复；原失败状态保留在PREFETCH-01/summary.json。

一次性测速与汇总脚本已移出当前版本，可从提交ccccb1d恢复查阅。保留预取实现及test_prefetch.py回归测试，避免以后改动破坏数据顺序和恢复能力。正式重启使用新的-pf1目录，从同一100轮起点重新训练；不沿用已取消的阶段权重。
